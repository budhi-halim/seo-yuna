    Owner access

    Set up this browser once, then log in with your chosen username and password.

    Set up this browser

    A GitHub token connects this browser to seo-yuna. Your chosen username and password keep that token encrypted on this device.

    Create GitHub token
    1. On GitHub, choose resource owner budhi-halim.
    2. Under Repository access, choose Only select repositories and select seo-yuna.
    3. Check Contents and Actions are both Read and write. The link selects a 90-day expiration.
    4. Generate the token and paste it below. Then choose the two strings you will use to log in here.

    Paste a fine-grained token for seo-yuna. It is encrypted in this browser and sent only to GitHub.

    Choose your own username and a password of at least 12 characters, preferably several unrelated words. Both are case-sensitive and stay on this device.

    Setup is saved in this browser. You will need a token again after clearing site data, changing browsers, or replacing an expired token.

    Prompt repositorybudhi-halim/seo-yuna
    Reset or replace this connection

    Remove the encrypted token saved in this browser, then set up a new token or login. Your prompts and GitHub token are not deleted. Revoke an old token in GitHub settings if you no longer use it.
